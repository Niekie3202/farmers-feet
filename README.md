# Farmer's Feet

A Fabric mod for Minecraft Java Edition that adds a boot enchantment which stops you from trampling farmland. Jump or fall onto farmland while wearing enchanted boots and the soil, and the crops on it, stay intact.

## Features

- **Farmer's Feet** enchantment for boots (maximum level I).
- Only available as an enchanted book:
    - a small chance (5%) in village chests
    - offered by librarians like any other enchanted book
    - offered by expert-level farmers for 5 emeralds and a book
- Not available in enchanting tables, and boots with the enchantment cannot be found in chests or bought from villagers.
- **Gentle Steps** advancement (Husbandry tab).

## Requirements

- Fabric Loader
- [Fabric API](https://modrinth.com/mod/fabric-api)

Install the mod on the server and, for the correct enchantment and advancement names, on the clients as well.
